# PR Agent · 汽车品牌传播提案工作台

> **作品案例**：<https://biu0716.github.io/portfolio/pr-agent.html> ｜ **在线体验**：<https://pr-agent.preview.tencent-zeabur.cn> ｜ **代码**：本仓库

一个面向汽车公关场景的 AI 工作台：给一句传播需求，自动产出「传播策略骨架 + 具体交付内容」，并支持稿件审校、术语规范化，以及基于知识库的语义检索。

由一名有 4 年汽车科技品牌传播经验的从业者**独立完成**（需求、设计、开发、上线全程一人）——把真实公关工作流里的判断（先对齐传播策略、再落交付，正式稿优先、版本越新越优先）直接编码进产品逻辑，而非套用通用模板。

> 本在线 Demo 运行在 **DEMO_MODE** 下，使用一套**完全虚构、脱敏**的示例品牌素材（「星航 NOVA」），不含任何真实客户资料。
>
> ⚠️ 在线体验跑在按量计费的服务器上，偶尔会关闭；若链接打不开，请看常驻在线的「作品案例」。

## 它能做什么

- **写一份新提案**：两阶段生成——先出传播策略判断，再出新闻稿段落、传播方向、媒体标题、社媒文案，可逐段重写、整体优化、一键导出。
- **改一篇现有稿子**：审稿挑错 / 术语规范化 / 正式风格改写。
- **查资料、找素材**：语义召回 + 规则重排（车型匹配、文档类型、版本新鲜度、质量分），并展示每条结果的得分构成。

## 怎么试用（无需安装）

体验这个产品**不用下载、不用配置环境**，打开在线地址即可：

1. 打开在线体验：<https://pr-agent.preview.tencent-zeabur.cn>
2. 首页选「**写一份新提案**」，点上方任意一个例子（比如「为旗舰纯电轿车 NOVA S9 全球首发写一版传播提案」），再点「生成提案」，约十几秒出结果。
3. 想看检索能力，回首页选「**查资料、找素材**」，点「NOVA S9 传播亮点」，结果里每一条都附**得分构成**，能看到「为什么这条排第一」。
4. 想看审稿能力，选「**改一篇现有稿子**」，点「填入一段示例新闻稿」，再点「开始处理」。

> 示例库是一套完全虚构、脱敏的品牌素材（「星航 NOVA」），里面真实存在 NOVA S9 / V9 / X7 / C3 四款车，上面的例子点下去都能出结果。
>
> 在线 Demo 跑在按量计费的服务器上，**偶尔会处于关闭状态**；若链接打不开，可改看常驻在线的图文作品案例：<https://biu0716.github.io/portfolio/pr-agent.html>，或参考下方「本地运行」自行启动。

## 技术栈

Python · FastAPI · FAISS · sentence-transformers（bge-small-zh）· 规则化重排 · 原生前端

## 一个被修掉的真实问题

检索的车型识别原本用「子串包含」，导致 "CLA" 命中 "S-CLASS" 里的 c-l-a，把整批 S 级文档误判后打成 UNKNOWN——约占全库 35% 的内容因此搜不到。改为「带词边界的匹配」后，这些内容全部恢复，且无误伤。

## 本地运行

```bash
pip install -r requirements.txt
# 真实库（自己用）：
uvicorn app:app --reload --port 8000
# 演示模式（脱敏示例库 + 限流）：
DEMO_MODE=1 uvicorn app:app --port 8000
```

需在环境变量 `AIHUBMIX_API_KEY` 中提供 LLM key。
